# Sukhi Fireworks — Design System (Festive Radiance / Light UI)

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| `primary` | `#ff6a00` | CTAs, accents, brand |
| `secondary` | `#306577` | Secondary actions |
| `background` | `#ffffff` | Page background |
| `surface` | `#fff8f5` | Cards, elevated surfaces |
| `on-surface` | `#1c1917` | Primary text |
| `outline` | `#8e7164` | Borders, dividers |
| `error` | `#dc2626` | Errors, sale badges |
| `success` | `#059669` | In-stock, success states |

## Typography

- **Display / Headlines**: Space Grotesk (600–700)
- **Body / UI**: Plus Jakarta Sans (400–800)
- **Icons**: Material Symbols Outlined

## Components

- **Cards**: `rounded-2xl`, subtle border `#e9e1dd`, soft shadow
- **Buttons**: Primary = filled orange rounded-full; Secondary = outlined
- **Badges**: Sale = red rounded-md; In-stock = emerald with check icon
- **Bottom Nav** (mobile): Fixed, blurred white, rounded top

## Spacing

- Consistent use of Tailwind spacing scale
- Section gaps: `mb-8` / `mb-12`
- Card padding: `p-4`

## Interaction

- Hover: slight lift + orange glow (`glow-hover`)
- Transitions: 200–300ms ease
- Toast notifications: bottom-right, auto-dismiss

## Theme

Clean light/white UI optimized for daytime readability and festive energy via the orange primary accent.
